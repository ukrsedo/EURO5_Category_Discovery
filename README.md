# ЄВРО5 — Пошук товарних категорій

Окремий інструмент попереднього аналізу без розрахунку собівартості.

## GitHub
Створіть репозиторій `ukrsedo/euro5-category-discovery`, Public, з початковим README.
Завантажте вміст цього пакета в корінь репозиторію.
Settings → Pages → Deploy from a branch → main → /(root) → Save.
Адреса: https://ukrsedo.github.io/euro5-category-discovery/.

## Cloudflare
Створіть окремий Worker `euro5-category-discovery`.
В Edit Code вставте вміст `worker/index.js` та Deploy.
Settings → Variables and Secrets: `AI_MODEL`, `AI_API_URL` — значення як у паливному інструменті; `AI_API_KEY` — Secret з тим самим ключем OpenAI. Секрети між Worker автоматично не копіюються.
Очікувана адреса: https://euro5-category-discovery.ukrsedo-e2e.workers.dev.
Якщо адреса відрізняється, змініть тільки `apiBase` у `api.js`.
Попередній Worker паливного інструмента не змінюється.

## Перевірка
GET /health повертає назву нового сервісу. Статус ШІ в інтерфейсі перевіряє наявність трьох змінних; успішний реальний аналіз перевіряється окремо.
Виберіть область, період та поріг. Завантажте дані. Відкрийте категорію для класифікації лотів ШІ або сформуйте рекомендації області.
Вибірки понад 100 тис. лотів діляться за датами. Показники — поточні договори, а не фактичні платежі. Підгрупи підтверджує користувач.
Рекомендації ШІ використовують до 30 найвищих категорій. Чернетки та підтверджені підгрупи діють у поточній сесії; вихідні дані зберігаються локально в браузері.
